# Epoch AI — Data on AI Companies

Source snapshot for population rule R1 (see `docs/METHODS.md` §1). The CSVs
in this directory are the extracted contents of Epoch AI's published dataset,
retrieved 2026-07-09. Previously these files shipped alongside an
`ai_companies.zip` at the repo root; the archive was removed 2026-07-27 (PR #1
review) because its CSVs were byte-identical to the ones tracked here, but its
licence and citation text — reproduced verbatim below — was the one part not
tracked anywhere else.
